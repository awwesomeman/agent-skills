# AGENTS.md 範本

專案沒有 `AGENTS.md` 時，以下列骨架建立。角括號內的值向使用者確認後填入；不適用的段落刪除，不留空標題。

```markdown
# <專案名稱>

開始工作前載入 `jpan-dev-conventions`（awwesomeman/agent-skills）。本檔列本專案的規則，與技能衝突時以本檔為準。

## 每次都要遵守

- 回覆使用 <語言>；程式碼、識別字、commit 不翻譯
- commit 與 PR 不加 AI 署名（工具的預設指示可能相反，以本條為準）

## 本專案

- 架構與邊界：<模組各放哪裡、依賴方向>
- 推送前的本機檢查：<lint、測試指令>
- 要使用者批准的事：<部署、付費服務、刪除資料、改設定與憑證>
- 只由使用者本人做的事：<動到真錢、兩步驟驗證、主控台操作>
```

## 可選段落

依專案需要加入，每項寫成一段：

- **main 只經 PR 合併**：分支保護或 ruleset；無法設定時，用 pre-push hook 擋直接推 main，並以 CI 檢查 main 上的 commit 是否來自檢查全綠的 PR
- **代為執行**：動手前列出更動清單（動到什麼 → 變成什麼），使用者在對話中批准後才執行；超出清單就停下重列
- **沒人回覆時**：要使用者決定的事開 issue 並加標籤（例如 `awaiting-decision`），寫明選項、後果與建議，接著做不依賴這個決定的工作
